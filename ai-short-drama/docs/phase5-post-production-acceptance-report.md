## 完整功能清单

### 口型与对白时间

- 逐句保存说话人、开始/结束、音频时长、目标/检测口型区间和分析器版本；
- 画面人物、检测说话人与指定说话人一致性；
- 可配置毫秒偏差检测和问题持久化；
- 多人对白轮次、重叠和顺序校验；
- 文案压缩、停顿调整、镜头延长和有限变速建议；
- worker 强制对白/旁白速度在 `0.80–1.12`，拒绝过度加速；
- 对白修改只创建相关音频、字幕、镜头区间和时间线区间后继版本。

### BGM、SFX 与环境声

- `bgm_hint`、`sound_effect_hint` 转为正式资产任务；
- BGM、环境声、音效、脚步、门响和打斗分类；
- 来源、版本、情绪、BPM/拍号/调性、时长、哈希和授权字段；
- 情绪曲线/节拍绑定、卡点、淡入淡出、转调、增益和对白 ducking；
- cue 与画面事件毫秒时间码对齐；
- 整集声音风格替换创建资产/cue/时间线后继版本并保留原版本。

### 剪辑策略模板

- 都市爽剧、情感剧、悬疑剧、喜剧、动作剧五套模板；
- 镜头长度、快切/反应镜头、转场、字幕、BGM/SFX 密度、特写、停顿、重复强调和节拍策略；
- 模板本体和版本分离；
- 项目级默认、单集级覆盖和覆盖配置；
- 每次切换创建新的时间线版本。

### 统一创作工作台

- 场景拖拽、节拍时间轴和逐句对白编辑；
- 分镜缩略图、拆分/合并/换序计划和时长修改；
- 对白转旁白/动作；
- 候选、版本和时间线历史；
- 表演圣经、角色状态、连续性、视觉 QC 和综合质量问题；
- 图片、视频、音频和字幕多轨时间线；
- 绑定场景/对白/镜头/时间码的评论；
- 问题直接跳转和结构化局部修改计划；
- 模板应用、整集声音风格替换、旧时间线恢复。

### 最终集成与追溯

- 同一 Mock 单集贯通诊断→节奏→候选→剧本→分镜→视觉一致性→视频→配音→口型→声音→剪辑→QC；
- 产物关联 Source Span、IR Fact、Adaptation Spec、Prompt/模型版本和人工修改记录；
- 已批准版本由数据库触发器防止原地覆盖；
- 恢复动作创建后继版本；
- artifact dependency 和精确时间区间共同决定重建范围；
- QC 问题保存实体和时间码编辑链接。

## 关键验收场景

1. fixture 在同一 project/episode ID 下建立来源、IR、Spec、诊断、节奏、候选、剧本、分镜、图片、视频、配音、字幕、声音、时间线、表演圣经、连续性、视觉 QC、母版和最终 QC。
2. 工作台查询能同时读取上述实体，不产生平行数据孤岛。
3. 修改单句对白后，原对白相关字幕和时间线仍可查询；新 current 只替换目标毫秒区间。
4. 项目模板、单集覆盖、历史恢复分别创建连续的时间线版本。
5. 整集声音风格替换创建新 cue 和时间线，保留原授权/来源版本。
6. 每个关键产物具备来源证据、Prompt/模型或人工修改事件。

## 剩余限制

- 口型、ASR、图像/视频和声音供应商均为确定性 Mock；尚未用真实演员素材和外部供应商评测精度、延迟、费用或失败恢复。
- 分镜拆分/合并在工作台中以可确认的结构化局部修改计划表示，沿现有执行链物化；当前没有自由式 NLE 那样的原子多镜头图形编辑事务。
- 多轨时间线用于编排、定位和版本控制，尚不是带波形、逐帧预览和 J/L-cut 手柄的桌面级 NLE。
- BGM 转调只执行人工或上游 manifest 明确指定的半音值，没有自动音乐学分析。
- 验收覆盖本地 Compose 和 Mock master，没有执行生产发布、真实 CDN、真实授权服务或移动端大项目性能测试。

## 推荐的后续优化

以下为后续版本建议，本阶段不继续扩展：

1. 用已授权的真实对白样本建立 ASR、说话人和口型检测基准集，量化不同景别/遮挡下的误差。
2. 将分镜拆分/合并计划升级为原子多实体后继版本执行器，同时保持现有确认、连续性和增量重建门禁。
3. 为长单集增加代理媒体、波形、虚拟滚动和分页，验证百场景/千 cue 的工作台性能。
4. 增加真实声音授权服务校验、供应商熔断和渲染成本/延迟观测。
5. 在预发布环境以真实 FFmpeg 素材补充响度、峰值、ducking、字幕安全区和跨播放器兼容性基准。
